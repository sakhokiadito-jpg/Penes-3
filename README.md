- OWNER PANEL;

## Запуск

1. Создать .env.
2. Вставить BOT_TOKEN.
3. Установить зависимости:

pip install -r requirements.txt

4. Запустить:

python bot.py

API:

uvicorn web.app:app --host 0.0.0.0 --port 8000

## Telegram Payments

Для цифровых услуг используется Telegram Stars (XTR).

После успешной оплаты бот автоматически
начисляет кредиты.

## Безопасность

Проект предназначен только для публичных
и законно используемых источников.

Не добавлять:

- утечки;
- приватные базы;
- SMS/CDR;
- пароли;
- токены;
- обход авторизации;
- CAPTCHA bypass;
- получение закрытых данных;
- автоматическую идентификацию человека
  по фотографии с формированием персонального досье.
